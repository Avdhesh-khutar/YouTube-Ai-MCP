# Browser Cinematic Planner

Open the [planner source](index.html) in GitHub to inspect the single-file page. It is
static HTML with inline JavaScript and CSS; it makes no external network/API requests.

## What it does

- Accepts a topic, audience, style, and extra instructions.
- Builds a structured Hindi 8–10 minute production brief and six-part scene outline.
- Offers a copy-to-clipboard action when the browser permits clipboard access.

## What it does not do yet

- It does not call an AI model or perform web research.
- It does not generate images, image-to-video clips, Hindi narration, or music.
- It does not render an MP4 or upload to YouTube.
- It does not need a download or installation, but GitHub's file preview may not execute
  the page as an interactive website. A hosted deployment would be a separate step.

## Safety

No remote scripts or API requests are used. The page clearly labels itself as a planning
tool, not a completed video generator. Any future upload integration must remain Private
and must not publish publicly without explicit owner approval.
