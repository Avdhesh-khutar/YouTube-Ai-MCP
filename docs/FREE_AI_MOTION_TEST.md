# Free browser AI-motion test (review-only)

## Goal
Verify one real image-to-video MP4 clip before wiring a provider into the cinematic pipeline. A still image with FFmpeg zoom/pan is not an AI-motion success.

## Free test candidate
Use [NiftyVid](https://igorcsis.github.io/nifty-vid/), a browser UI using the open Wan 2.2 image-to-video model through a public Hugging Face Space. It uses shared free GPU capacity, so queues, cold starts, and upstream failures are possible. Review the current page before use; free availability is not guaranteed.

## Test recipe
1. Prepare one non-sensitive 16:9 scene image as PNG/JPG/WebP.
2. Open NiftyVid in a browser and upload the image.
3. Use this prompt: `Cinematic natural movement: camera slowly pushes forward; tree leaves sway gently in a light breeze; subtle mist drifts in the background; realistic physics, stable subject, no scene cuts or morphing, preserve the original composition.`
4. Request about 3.5 seconds and keep default settings for the first attempt.
5. Download the MP4 only if generation succeeds. Do not enter payment details, tokens, or private images.
6. Confirm the file is playable video and inspect flicker, warping, object morphing, and camera jumps.
7. Only after review, place the clip beside its source image using the same basename, e.g. `scene-02.png` and `scene-02.mp4` in `assets/cinematic-scenes/`.
8. Run the review render workflow on this feature branch and inspect the final MP4 and report. Never upload to YouTube as part of this test.

## Acceptance criteria
- Real, playable MP4 with non-zero size and video frames.
- Subject/background motion is generated by image-to-video AI, not just zoom/pan.
- Motion is coherent enough for a cinematic edit.
- Renderer uses the MP4 for the matching scene.
- Full video/audio/subtitle checks remain separate; a short clip does not prove the 8–10 minute pipeline works.

## Integration limitation
NiftyVid uses its own browser/Worker streaming contract. Do not assume it is compatible with `scripts/hf_space_i2v.py`. Do not hard-code a Gradio endpoint or claim automatic integration until the live API schema is verified and a real MP4 is returned.

## Safety
- No YouTube API calls or uploads.
- Keep changes on `feature/cinematic-video-pipeline`; do not merge the draft PR without owner approval.
- No paid APIs, paid credits, private credentials, or non-consensual/private source images.
- If the public demo is unavailable, record the test as blocked; never substitute a fake clip or claim success.
